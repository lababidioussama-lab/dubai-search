Server address
  1. Match Text https?://\S+ in Shortcut Input, then Get Item from List → First Item.
  2. Get Contents of URL → the server address above, Method POST.
    Headers Content-Type: application/json, Authorization: Api-Key … · JSON body url = Item from List
  3. Get Dictionary Value status. If it is picker, repeat over picker and take each url; otherwise take url. Add each to variable Links.
  4. Repeat with Each in Links → Get Contents of URL → Save to Photo Album.

FAQ

Questions

What is the access key?

The server is private. The key keeps strangers from using it. Tap “Access key” under the box, paste it once, and this browser remembers it.

The download opened in a new tab instead of saving

Some sites only allow viewing in the browser. On iPhone tap the share icon → Save Video; on a computer right-click the video → Save video as.

A link doesn't work

Private posts, stories that expired, and age-restricted content can't be fetched. Instagram and YouTube sometimes limit downloads from servers — try again a little later.

Is this legal?

Saving videos for personal use is generally fine. Only re-upload or share content you own or have permission to use.
